# 周雨悦 · 个人作品集网站

一个暗色 × 荧光绿风格的创意作品集网站，用于向 2027 秋招面试官展示你的作品与简历。
不需要任何编程基础也可以更新和使用。

---

## 1. 先看看效果

**本地预览**：双击打开 `index.html`，浏览器就会显示网站。
（推荐用 Chrome 或 Safari 打开，效果最好。）

---

## 2. 如何发布上线（让别人能用网址访问）

网站是一整个文件夹，上传到任意静态托管平台即可，推荐下面两种：

### 方式一：GitHub Pages（免费，推荐）
1. 注册/登录 [github.com](https://github.com)，新建一个仓库（Repository），名字随意，比如 `portfolio`。
2. 把本文件夹里的**所有内容**上传到仓库（网页右上角 Add file → Upload files，直接拖进去）。
3. 打开仓库的 **Settings → Pages**，在 "Source" 里选择 `Deploy from a branch`，分支选 `main`，文件夹选 `/ (root)`，点 Save。
4. 等 1~2 分钟，你的网站就会出现在 `https://你的用户名.github.io/portfolio/`。

### 方式二：Vercel（免费，速度快）
1. 注册 [vercel.com](https://vercel.com)。
2. 点击 **New Project** → 导入你的 GitHub 仓库 → **Deploy**，全程自动。
3. 完成后会得到一个 `https://xxx.vercel.app` 的网址。

> 也可以把 `portfolio-site` 这个文件夹单独发到任何支持静态网站的云服务（阿里云 OSS、腾讯云 COS 等），把文件上传后开启"静态网站托管"即可。

## 3. 作品视频怎么放上去（重要）

目前网站上的视频作品都已填好 B 站链接、可直接在线观看（《看不见的伙伴》AI 公益广告、调色划像对比、麦当劳「百人派对」、娃哈哈广告、AE 特效合集、预告片剪辑）。
**推荐做法：把视频上传到 B 站（bilibili.com），然后把链接填进去。**

操作步骤：
1. 打开 `script.js`（用记事本 / 文本编辑打开即可）。
2. 找到最上方的 `VIDEO_LINKS` 区域，大概长这样：

```js
const VIDEO_LINKS = {
  gongyi: "https://b23.tv/qSVVKEf",  // 《看不见的伙伴》AI 公益广告（已填）
  grading: "https://b23.tv/RdkVtl2", // 调色划像对比-婚礼（已填）
  mcd: "https://b23.tv/JlGxBq2",     // 麦当劳「百人派对」活动视频（已填）
  wahaha: "https://b23.tv/6H7W8jh",  // 娃哈哈 广告视频（已填）
  ae: "https://b23.tv/4tjR2TU",     // AE 特效合集（已填）
  trailer: "https://b23.tv/lLo4Ok1", // 预告片剪辑（已填）
};
```

3. 把对应视频的 B 站链接粘贴到引号里，例如 `gongyi: "https://www.bilibili.com/video/BVxxxxxx"`。
4. 保存文件，刷新网页即可。留空的视频会自动显示「联系我获取完整视频」。

> 小提示：
> - 作品详情弹窗顶部就是「前往观看 / 前往查看」大按钮，点一下直接跳转；介绍文字在下方，预览图在介绍之后，浏览顺序很顺。
> - 部分作品卡片带「成果角标」（如 13.7K 赞藏、60+ 家庭到场）；3 个代表作品（动物园怪谈 / AI 公益广告 / 抖音爆款）弹窗里有「我的创作手记」，讲灵感来源与翻车迭代过程。
> - 首页新增「我的爆款方法论」板块（拆爆款 → 再造爆款 → 测试迭代 · 数据验证）；还有鼠标光效、打字机标语、自定义光标、控制台彩蛋（按 F12 可看到）等小惊喜，桌面浏览器体验最佳。
> - 《锈湖血灾》AI 二创视频已改为**抖音链接**观看（原视频 23MB，为避免上传超限改成了链接，原文件备份在 outputs 的「备份-锈湖血灾-原视频」文件夹里）。
> - 《动物园怪谈》互动游戏已内置「在线试玩」和「小红书宣传帖（视频帖 + 图文帖两篇）」直达链接，无需额外配置。
> - 「关于我」里的方形二维码图片是你的百度网盘完整版作品集分享码，已标注清楚，不会被误认为是联系方式。

## 4. 怎么更新简历

直接把新的 PDF 简历**替换** `assets/pdf/简历.pdf` 这个文件（文件名保持「简历.pdf」即可），
网站的「下载简历」按钮就会自动指向新文件。

---

## 5. 怎么修改联系方式

打开 `index.html`，找到底部「联系」区域（搜索 `contact` 或 `WECHAT`）：
- **邮箱 / 电话**：直接修改文字和 `mailto:` / `tel:` 链接。
- **微信**：已填为 `zyy2005yyyy`，如需修改，把 `index.html` 里 `zyy2005yyyy` 换成新微信号即可。
- 简历按钮链接在顶部导航和联系区各有一处，均指向 `assets/pdf/简历.pdf`。

## 6. 文件夹结构

```
portfolio-site/
├── index.html          # 网页内容（文字、联系方式在这里改）
├── styles.css          # 样式（配色、字体、动画）
├── script.js           # 作品数据 + 视频链接配置
├── assets/
│   ├── img/            # 图片（调色对比图、作品集封面）
│   ├── pdf/            # 简历、策划案、平面合集等文档
│   └── video/          # 嵌入的视频
└── README.md           # 本说明
```

## 7. 常见问题

- **网站打开是空白？** 确认是否直接双击 `index.html` 打开的；如果用某些编辑器预览可能不支持。请用 Chrome / Safari 打开。
- **视频播不了？** 检查浏览器是否最新版；《锈湖血灾》是 H.264 格式，Chrome / Safari / Edge 都支持。
- **想换配色 / 文字？** 颜色在 `styles.css` 顶部的 `:root` 区域，改几个色值即可；文字在 `index.html` 里直接改。
- **想让网站更轻？** 可以删除 `assets/video/` 和 `assets/pdf/` 里的大文件，把作品都改成链接（见第 3 节）。
